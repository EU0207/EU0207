## 🎫 コンサート受付システム（開発中）

QRコードを利用して、コンサート当日の受付業務と
来場状況の管理を効率化するシステムです。

実際の利用者へのヒアリングをもとに、
要件定義と技術検証を一人で進めています。
Codexを開発支援に活用しながら、提案内容の確認、
採否の判断、テストによる検証を自分で行っています。

- **検証環境**: TypeScript / Vite / PWA / Firebase / IndexedDB
- **利用端末**: スマートフォン / PCを想定
- **開発方法**: Codexを活用したAI支援開発
- **主な機能**:
  - QRコードによる来場受付
  - 二重受付・無効チケットの判定
  - 通信できない環境での受付継続と復旧後のデータ統合
  - 来場状況・座席・例外対応・操作履歴の管理
- **開発フェーズ**: 要件定義・技術検証中

> 🧪 複数端末でのオフライン受付、QRコードの読み取り、
> 同期性能、権限制御などをPoCで検証しています。

※ 現在は要件と受入条件の確定に向けて開発中です。

※ 記載している技術構成や機能は、
今後の検証・設計によって変更する場合があります。

## 🎋 SOU Touch（開発中）

スマートフォンで箏（こと）の演奏を疑似体験できるアプリです。

個人のブランド名義で開発しており、
企画・設計・実装をすべて一人で担当しています。

- **環境**: Unity 6 LTS / C# / URP / New Input System
- **対応OS**: iOS 15.0以降 / Android 8.0以降（開発予定）
- **開発方法**: ClaudeCodeを活用したAI支援開発
- **主な機能**:
  - 13弦のタップ・スワイプによる演奏
  - 押し手（ピッチベンド）操作
  - 調弦・録音機能
- **開発フェーズ**: アルファ版に向けて実装中
