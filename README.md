## 個人開発

### 🎫 コンサート受付システム（開発中）

個人コンサートの名簿・座席管理と当日のQR受付を支援するWebアプリです。主催者へのヒアリングをもとに、要件定義から設計・実装・テストまで一人で担当しています。

**[操作デモを開く（ログイン不要）](https://eu0207.github.io/concert-reception-system/)**  
デモは架空データのUIモックです。製品は開発中で、本番利用はできません。

[リポジトリ・開発資料を見る](https://github.com/EU0207/concert-reception-system)

- **技術**：TypeScript、Vite、PWA、Firebase、IndexedDB
- **設計の工夫**：会場の回線が不安定でも受付を続けられるよう、端末内への保存と通信復旧後の再送を設計しました。
- **進捗**：要件定義と設計の承認を経て、座席計算・端末保存・認可の基盤と業務画面の結合を進めています。

Codexを開発支援に活用し、提案の採否とテスト結果は自分で確認しています。

### 🎋 SOU Touch（開発中）

スマートフォンで箏（こと）の演奏を疑似体験できるアプリです。企画・設計・実装を一人で担当し、アルファ版に向けて開発しています。

- **技術**：Unity 6 LTS、C#、URP、New Input System
- **対応予定**：iOS 15.0以降、Android 8.0以降
- **機能の範囲**：13弦のタップ・スワイプによる演奏、押し手（ピッチベンド）、調弦・録音
- **開発支援**：Claude Code

リポジトリは非公開です。デモ動画は準備中です。
